# Making a recording (Fuse)

Before recording: Options -> RZX -> turn OFF "autosave". Load the SAME .z80 you
will give the agent (title screen, keyboard controls).

Record one session of 3-5 minutes that includes:
1. Start the game from the title screen with the keyboard.
2. Walk and jump through at least 6-8 different rooms.
3. Pick up, drop and use an item; open the inventory.
4. Talk to a character (dialogue boxes) if the game has them.
5. Lose a life (fall, hazard or enemy) and continue.
6. Stand next to / under anything that moves or falls (enemies, lifts, objects).
7. Anything special: water/underwater, climbing, lifts, conveyor belts.
8. Return to a room you already visited.

Name files consistently: `<game>.z80` and `<game>.rzx`.
